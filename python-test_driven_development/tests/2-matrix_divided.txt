===============================
How to use matrix_divided
===============================

Öncə funksiyanı import edək:
    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Normal hal: Matrisi rəqəmə bölmək
    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

Xəta: Divisor (bölən) sıfır olduqda
    >>> matrix_divided(matrix, 0)
    Traceback (most recent call last):
        ...
    ZeroDivisionError: division by zero

Xəta: Divisor rəqəm olmadıqda
    >>> matrix_divided(matrix, "yox")
    Traceback (most recent call last):
        ...
    TypeError: div must be a number

Xəta: Sətirlərin ölçüsü fərqli olduqda
    >>> matrix = [[1, 2, 3], [4, 5]]
    >>> matrix_divided(matrix, 2)
    Traceback (most recent call last):
        ...
    TypeError: Each row of the matrix must have the same size

Xəta: Matrisin daxilində rəqəm olmayan element olduqda
    >>> matrix = [[1, 2], [3, "salam"]]
    >>> matrix_divided(matrix, 2)
    Traceback (most recent call last):
        ...
    TypeError: matrix must be a matrix (list of lists) of integers/floats

Xəta: Matris ümumiyyətlə siyahı (list) olmadıqda
    >>> matrix_divided("bu matris deyil", 2)
    Traceback (most recent call last):
        ...
    TypeError: matrix must be a matrix (list of lists) of integers/floats

Orijinal matrisin dəyişmədiyini yoxlayaq:
    >>> matrix = [[1, 2], [3, 4]]
    >>> new_matrix = matrix_divided(matrix, 2)
    >>> matrix
    [[1, 2], [3, 4]]

Sonsuzluğa bölmə testi:
    >>> matrix = [[10, 20], [30, 40]]
    >>> matrix_divided(matrix, float('inf'))
    [[0.0, 0.0], [0.0, 0.0]]
