===============================
How to use text_indentation
===============================

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Normal istifadə:
    >>> text_indentation("Hello. How are you? Fine: Thanks.")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    Thanks.

Sətir başındakı boşluqların təmizlənməsi:
    >>> text_indentation("Start.    Spaces after dot.")
    Start.
    <BLANKLINE>
    Spaces after dot.

Xəta halları:
    >>> text_indentation(12345)
    Traceback (most recent call last):
        ...
    TypeError: text must be a string

Boş string:
    >>> text_indentation("")
