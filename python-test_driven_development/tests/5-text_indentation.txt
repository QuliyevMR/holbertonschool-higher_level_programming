The ``5-text_indentation`` module
=================================

Using ``text_indentation``
--------------------------

Import the function:
    >>> text_indentation = __import__('5-text_indentation').text_indentation

Normal string:
    >>> text_indentation("Hello. World? Fine: Done")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    Done

Error handling:
    >>> text_indentation(123)
    Traceback (most recent call last):
        ...
    TypeError: text must be a string

Multiple spaces:
    >>> text_indentation("Wait.    Check this out?   Cool.")
    Wait.
    <BLANKLINE>
    Check this out?
    <BLANKLINE>
    Cool.
    <BLANKLINE>
